Overview

What it does

  • Habits are easier to keep when someone else can see whether you actually did the thing.
  • You join a shared space with a group code, everyone's tasks are visible to the group, and progress updates in real time.
  • React Native and Expo on the front end, Supabase for real-time data.
  • The Gemini API suggests habits when a group runs out of ideas. Built in 24 hours at nwHacks.
